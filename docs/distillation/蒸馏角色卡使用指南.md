## 1. 系统概述

蒸馏角色卡系统将真实聊天记录转化为可运行的 AI 角色人格，包含两个阶段：

**阶段一：角色卡蒸馏**
```
聊天记录 → 解析 → LLM 分析 → 风格统计 → 融合 → 角色卡（Markdown + JSON）
```

**阶段二：LoRA 微调（可选）**
```
聊天记录 + 角色卡 → 训练数据构造 → LoRA/QLoRA 训练 → 微调推理引擎
```

最终产出物：
- **角色卡文件**：Markdown（Wiki 格式）+ SillyTavern JSON
- **LoRA adapter**：微调后的模型权重（可选，需要 GPU）
- **评测报告**：人格保真度六维度评分

## 3. 完整流程：从聊天记录到角色卡

假设你有一份微信/QQ 聊天记录导出文件，目标是生成"小雅"的角色卡。

```
第一步：蒸馏 → 得到角色卡（Markdown + JSON）
第二步：构造训练数据 → 得到 Alpaca/ShareGPT 格式的训练集
第三步：LoRA 训练 → 得到微调 adapter（可选）
第四步：人格评测 → 验证保真度
第五步：推理使用 → 用微调模型对话
```

## 4. Step 1：蒸馏生成角色卡

### 4.1 基本用法

```bash
# 从聊天记录蒸馏角色卡
uv run python -m vir_bot.core.distillation.cli \
    --input data/chat_records/wechat_export.json \
    --name "小雅" \
    --evaluate
```

### 4.2 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--input, -i` | 聊天记录文件路径（JSON/NDJSON/TXT） | 必填 |
| `--name, -n` | 角色名称 | 必填 |
| `--output, -o` | Markdown 输出目录 | `./data/wiki/characters/` |
| `--json-output` | SillyTavern JSON 输出目录 | `./data/characters/` |
| `--evaluate, -e` | 执行评测 | 否 |
| `--judge` | 使用 LLM-as-Judge 评测 | 默认开启 |
| `--no-judge` | 禁用 LLM-as-Judge | 否 |
| `--dry-run` | 预览模式，不写入文件 | 否 |
| `--incremental` | 增量模式（基于已有角色卡更新） | 否 |
| `--existing` | 增量模式下的已有角色卡路径 | 无 |
| `--parser` | 指定解析器（generic/wechat/qq/discord） | auto |
| `--chunk-size` | 分块大小（每块对话轮数） | 400 |
| `--timeout` | 单次 LLM 调用超时秒数 | 120 |
| `--verbose, -v` | 详细输出（-v 或 -vv） | 否 |

### 4.3 输出文件

```
data/wiki/characters/小雅.md          # Markdown 角色卡（Wiki 格式）
data/characters/小雅.json             # SillyTavern V2 JSON 角色卡
```

### 4.4 增量更新

已有角色卡但新增了聊天记录，可以增量更新：

```bash
uv run python -m vir_bot.core.distillation.cli \
    --input data/chat_records/new_chats.json \
    --name "小雅" \
    --incremental \
    --existing data/wiki/characters/小雅.md \
    --evaluate
```

## 5. Step 2：构造 LoRA 训练数据

将聊天记录和角色卡转化为 LoRA 微调所需的训练数据。

### 5.1 使用 CLI

```bash
uv run python -m vir_bot.core.distillation.cli build-data \
    --dialogue-file data/chat_records/wechat_export.json \
    --profile-file data/characters/小雅.json \
    --output data/training/小雅_train.json \
    --format alpaca \
    --stages a b c
```

### 5.2 使用 Python API

```python
from vir_bot.core.distillation.finetune import create_builder
from vir_bot.core.distillation.analyzer.extractor import PersonaProfile
import json

# 加载角色画像
with open("data/characters/小雅.json", "r", encoding="utf-8") as f:
    profile = PersonaProfile(**json.load(f))

# 加载对话数据
with open("data/chat_records/wechat_export.json", "r", encoding="utf-8") as f:
    dialogues = json.load(f)

# 构造训练数据
builder = create_builder(window_size=5, max_stage_a_pairs=2000)
result = builder.build(
    dialogues=dialogues,
    profile=profile,
    output_path="data/training/小雅_train.json",
    output_format="alpaca",
    stages=["a", "b", "c"],
)

print(f"总样本数: {result.total_count}")
print(f"Stage A (风格对话): {result.stage_a_count}")
print(f"Stage B (指令对): {result.stage_b_count}")
print(f"Stage C (场景对): {result.stage_c_count}")
```

### 5.3 三阶段训练数据说明

| 阶段 | 方法 | 数据来源 | 说明 |
|------|------|---------|------|
| Stage A | 风格对话对 | 聊天记录 | 滑动窗口提取 (context, response) 对，还原说话风格 |
| Stage B | 指令对 | 角色卡 | 从 PersonaProfile 生成问答对，覆盖身份/风格/情感/价值观 |
| Stage C | 场景对 | 角色卡 | 26 个预定义场景模板，测试角色在特定情境下的反应 |

### 5.4 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--dialogue-file` | 对话记录文件（JSON） | 必填 |
| `--profile-file` | PersonaProfile 文件（JSON） | 必填 |
| `--output, -o` | 输出文件路径 | 自动生成 |
| `--format` | 输出格式（alpaca/sharegpt） | alpaca |
| `--stages` | 训练阶段（a/b/c） | a b c |
| `--max-stage-a` | Stage A 最大样本数 | 2000 |
| `--window-size` | 滑动窗口大小 | 5 |

### 5.5 输出格式

**Alpaca 格式**（兼容 HuggingFace SFTTrainer、LLaMA-Factory）：
```json
[
  {
    "instruction": "你是一个叫小雅的女生...",
    "input": "",
    "output": "回复内容"
  }
]
```

**ShareGPT 格式**（兼容更多训练框架）：
```json
[
  {
    "conversations": [
      {"from": "human", "value": "用户消息"},
      {"from": "gpt", "value": "角色回复"}
    ]
  }
]
```

## 6. Step 3：LoRA 微调训练

### 6.1 使用 CLI

```bash
# 全精度 LoRA（需要 24GB+ 显存）
uv run python -m vir_bot.core.distillation.cli train \
    --train-file data/training/小雅_train.json \
    --base-model Qwen/Qwen2.5-7B-Instruct \
    --epochs 3 \
    --lora-rank 32 \
    --output-dir data/lora_adapters \
    --adapter-name 小雅_adapter

# QLoRA（8GB 显存即可）
uv run python -m vir_bot.core.distillation.cli train \
    --train-file data/training/小雅_train.json \
    --base-model Qwen/Qwen2.5-7B-Instruct \
    --use-qlora \
    --epochs 3 \
    --batch-size 2 \
    --output-dir data/lora_adapters \
    --adapter-name 小雅_adapter
```

### 6.2 使用 Python API

```python
from vir_bot.core.distillation.finetune import create_trainer
from vir_bot.core.distillation.finetune.lora_config import LoRAConfig

# QLoRA 配置（8GB 显存）
config = LoRAConfig.qlora_default()
config.base_model = "Qwen/Qwen2.5-7B-Instruct"
config.num_epochs = 3
config.output_dir = "data/lora_adapters"
config.adapter_name = "小雅_adapter"

trainer = create_trainer(config)
result = trainer.train(train_file="data/training/小雅_train.json")

print(f"Adapter 路径: {result.adapter_path}")
print(f"最终 Loss: {result.final_loss:.4f}")
print(f"耗时: {result.training_time_seconds / 60:.1f} 分钟")
```

### 6.3 训练参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--train-file` | 训练数据文件 | 必填 |
| `--eval-file` | 验证数据文件 | 自动分割 |
| `--base-model` | 基座模型 | Qwen/Qwen2.5-7B-Instruct |
| `--lora-rank` | LoRA 秩 | 32 |
| `--lora-alpha` | LoRA alpha | 64 |
| `--epochs` | 训练轮数 | 3 |
| `--batch-size` | 批大小 | 4 |
| `--lr` | 学习率 | 2e-4 |
| `--use-qlora` | 启用 QLoRA | 否 |
| `--qlora-bits` | 量化位数（4/8） | 4 |
| `--max-seq-length` | 最大序列长度 | 2048 |
| `--output-dir` | 输出目录 | ./data/lora_adapters |
| `--adapter-name` | adapter 名称 | persona_adapter |

### 6.4 输出文件

```
data/lora_adapters/小雅_adapter/
├── adapter_model.safetensors    # LoRA 权重
├── adapter_config.json          # LoRA 配置
├── tokenizer.json               # Tokenizer
├── training_config.json         # 训练配置（用于推理时自动加载基座模型）
└── ...
```

### 6.5 预设配置

| 预设 | 显存需求 | 适用场景 |
|------|---------|---------|
| `LoRAConfig.qlora_default()` | 8GB | 消费级显卡（RTX 3060/4060） |
| `LoRAConfig.full_lora_default()` | 24GB+ | 专业显卡（A100/4090） |

## 7. Step 4：人格保真度评测

基于 InCharacter (ACL 2024) 的心理访谈方法，六维度评测角色保真度。

### 7.1 使用 CLI

```bash
uv run python -m vir_bot.core.distillation.cli eval-persona \
    --adapter-path data/lora_adapters/小雅_adapter \
    --profile-file data/characters/小雅.json \
    --output data/eval/小雅_eval.json \
    --quick
```

### 7.2 使用 Python API

```python
from vir_bot.core.distillation.finetune import create_inference, create_personality_evaluator
import json

# 加载角色画像
with open("data/characters/小雅.json", "r", encoding="utf-8") as f:
    profile = PersonaProfile(**json.load(f))

# 创建推理引擎
engine = create_inference(
    adapter_path="data/lora_adapters/小雅_adapter",
    load_in_4bit=True,
)

# 创建评测器
evaluator = create_personality_evaluator()

# 执行评测
result = evaluator.evaluate(
    profile=profile,
    generate_fn=lambda q: engine.generate(q).text,
)

print(result.summary())
evaluator.save_report(result, "data/eval/小雅_eval.json")
```

### 7.3 评测维度

| 维度 | 权重 | 评测内容 |
|------|------|---------|
| 大五人格 | 25% | 开放性、尽责性、外向性、宜人性、神经质 |
| 说话风格 | 20% | 正式度、表情使用、句长、口头禅、语气 |
| 价值观 | 20% | 人生优先级、动机、禁忌、友情观 |
| 情感模式 | 15% | 悲伤/开心/愤怒/恐惧的反应模式 |
| 身份一致性 | 10% | 名字、年龄、经历等基本信息 |
| 边界安全 | 10% | 是否泄露系统信息、是否突破角色 |

## 8. Step 5：使用微调模型推理

### 8.1 交互模式

```bash
uv run python -m vir_bot.core.distillation.cli infer \
    --adapter-path data/lora_adapters/小雅_adapter \
    --system-prompt "你是小雅，一个活泼可爱的女生..." \
    --load-4bit
```

进入交互对话模式，输入 `quit` 退出。

### 8.2 单次推理

```bash
uv run python -m vir_bot.core.distillation.cli infer \
    --adapter-path data/lora_adapters/小雅_adapter \
    --system-prompt "你是小雅" \
    --input "今天天气真好啊" \
    --temperature 0.7
```

### 8.3 Python API

```python
from vir_bot.core.distillation.finetune import create_inference
from vir_bot.core.distillation.finetune.lora_inference import GenerationConfig

engine = create_inference(
    adapter_path="data/lora_adapters/小雅_adapter",
    load_in_4bit=True,
    generation_config=GenerationConfig(
        max_new_tokens=512,
        temperature=0.7,
        top_p=0.9,
    ),
)

# 单次生成
result = engine.generate(
    "今天心情不太好",
    system_prompt="你是小雅，一个温暖的女生，善于安慰别人。",
)
print(result.text)

# 流式生成
for chunk in engine.generate_stream(
    "给我讲个故事吧",
    system_prompt="你是小雅，喜欢讲故事。",
):
    print(chunk, end="", flush=True)
```

### 8.4 Adapter 热切换

支持运行时切换不同角色的 adapter：

```python
# 切换到另一个角色
engine.swap_adapter("data/lora_adapters/另一个角色_adapter")
```

## 9. 配置说明

### 9.1 AI 后端配置（config.yaml）

蒸馏流程依赖 LLM 进行分析，需要配置 AI 后端：

```yaml
ai:
  provider: "openai"           # ollama / openai / local_model
  openai:
    api_key: "sk-xxx"          # 或使用环境变量 VIRBOT_OPENAI_KEY
    base_url: "https://api.openai.com/v1"
    model: "gpt-4o"
```

### 9.2 环境变量

```bash
# AI API Key
export VIRBOT_OPENAI_KEY="sk-xxx"

# 或在 .env 文件中设置
echo 'VIRBOT_OPENAI_KEY=sk-xxx' >> .env
```

### 9.3 LoRA 训练配置

```python
from vir_bot.core.distillation.finetune.lora_config import LoRAConfig

# 查看默认配置
config = LoRAConfig()
print(config)

# 自定义配置
config = LoRAConfig(
    base_model="Qwen/Qwen2.5-7B-Instruct",
    lora_rank=32,              # 秩，越大拟合能力越强
    lora_alpha=64,             # 通常 2x rank
    lora_dropout=0.05,         # 防过拟合
    target_modules=[           # 应用 LoRA 的层
        "q_proj", "k_proj", "v_proj", "o_proj",
        "gate_proj", "up_proj", "down_proj",
    ],
    num_epochs=3,
    learning_rate=2e-4,
    max_seq_length=2048,
)

# 保存/加载配置
config.save("data/lora_adapters/my_config.json")
config = LoRAConfig.load("data/lora_adapters/my_config.json")
```

## 10. 常见问题

### Q: 没有 GPU 能用 LoRA 训练吗？

A: 可以用 CPU 训练，但速度极慢（7B 模型可能需要数天）。建议：
- 只使用阶段一（角色卡蒸馏），不需要 GPU
- 使用云 GPU（AutoDL、恒源云等，约 2-5 元/小时）
- 使用 QLoRA + 小模型（如 Qwen2.5-3B-Instruct）

### Q: 角色卡质量不好怎么改进？

A: 按优先级检查：
1. **聊天记录质量**：确保数据量足够（建议 5000+ 轮对话）
2. **AI 后端选择**：使用更强的模型（GPT-4o > DeepSeek > Qwen）
3. **增量更新**：用 `--incremental` 基于已有结果迭代改进
4. **人工校对**：直接编辑生成的 Markdown 角色卡

### Q: 训练数据格式不对怎么办？

A: `build-data` 命令支持 Alpaca 和 ShareGPT 两种格式。如果训练框架不兼容，可以用 Python API 自定义输出格式。

### Q: 评测分数低怎么办？

A: 
- 60-70%：正常水平，角色卡基本可用
- 70-80%：较好，主要特征已还原
- 80%+：优秀，细节也高度还原
- 低于 60%：检查训练数据质量，增加训练轮数或数据量

### Q: 如何在现有 AI 机器人中使用角色卡？

A: 两种方式：
1. **纯角色卡**：将 Markdown 角色卡内容作为 system prompt 注入（零成本，适合快速验证）
2. **LoRA 微调**：使用微调后的模型生成回复（需要 GPU，效果更好）
